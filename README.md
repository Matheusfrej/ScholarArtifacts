# ScholarArtifacts

## Dataset Attribution

This project uses the dataset associated with the following publication:

Stefan Winter, Christopher S. Timperley, Ben Hermann, Jürgen Cito, Jonathan Bell, Michael Hilton, and Dirk Beyer.  
"A Retrospective Study of One Decade of Artifact Evaluations."  
DOI: https://doi.org/10.1145/3540250.3549172

The dataset is licensed under the Creative Commons Attribution 4.0 International License (CC BY 4.0).

License: https://creativecommons.org/licenses/by/4.0/

The original data was provided in CSV format. For the purposes of this project, the dataset was transformed and imported into a PostgreSQL database for use within the API.
